# Velqora 4.0.1

- Corrigida a logo que aparecia vazia na barra lateral e em Configurações → Sobre o Velqora.
- Adicionada verificação de carregamento e renderização das duas logos para evitar que o problema volte.

Instale com `Velqora-Setup-Windows-v4.0.1.exe`. A atualização pelo aplicativo usa `SHA256SUMS.txt` para conferir o download. Para usuários da versão 3.2, o pacote também inclui o mesmo instalador com o nome compatível `Velqora-Setup-v4.0.1.exe`.

Os arquivos ficam em `publish/Release/`. A situação da assinatura digital está registrada em `SIGNING-STATUS.txt`.
